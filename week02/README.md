2주차 학습 내용

가상화의 종류(베어메탈:하나의 PC와 하나의 OS, 
          하이퍼바이저:하나의 PC에 여러 VM 실행, 
          컨테이너:하나의 PC OS로 여러 독립적인 실행환경 제공) 학습.
WSL: Windows에서 Linux 환경을 사용할 수 있도록 해주는 기술

리눅스 기본 명령어 학습
  ls (-l, -a, -la): 파일 목록 출력

  mkdir, rmdir: 디렉터리 생성, 삭제
  touch, rm: 파일 생성, 삭제

  cat, less, head, tail: 파일 내용 확인(전체 내용, 페이지 단위로, 앞부분만, 뒷부분만)

  !!, !ls, !103: 직전 명령어, ls로 시작한 직전 명령어, 103번째 명령어 실행

GIT: 코드 변경 이력을 관리하는 버전 관리 시스템
