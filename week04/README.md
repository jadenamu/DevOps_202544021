절대 경로와 상대 경로
  절대 경로: 루트 디렉터리부터 시작하는 경로 /home/user/devops/week04
  상대 경로: 현재 디렉터리를 기준으로 한 경로 ./week04

파일 내용 검색
  find: 조건에 맞는 파일 및 디렉터리 검색
  grep: 특정 문자열이나 패턴 포함
  head: 파일 앞부분 출력
  tail: 파일 뒷부분 출력
  wc -l: 입력된 텍스트 줄 수 계산
  find . -type f -name "*.sh" # 셸 스크립트 파일 찾기
  
  파이프(|): 앞 명령어의 출력을 뒤 명령어의 입력으로 연결
  리다이렉션(>): 명령어 출력 저장

자동화: 반복적인 작업을 일정한 절차로 실행

프로그램: 디스크에 저장된 실행 코드
프로세스: 실행 중인 프로그램
PID: 실행 중인 프로세스를 식별하는 번호

브렌치: 기존 작업 흐름과 분리하여 새로운 기능이나 수정을 진행할 수 있다

Pull Request:브렌치에서 작업한 변경 사항을 검토하고 다른 브랜치에 합치기 위해 요청하는 기능

네트워크
  IP 주소: 네트워크에서 장치를 식별하는 주소
  포트: 장치에서 실행 중인 서비스를 구분하는 번호
  DNS: 도메인 이름에 대응하는 IP 주소를 찾는 시스템
  NAT: 사설 IP 주소를 사용하는 장치가 공유기 등을 통해 인터넥과 통신하도록 주소를 변환.

TCP/UDP
  TCP와 UDP는 전송 계층에서 사용하는 프로토콜
  TCP: 데이터 전달의 신리성과 순서를 중요하게 다룸
  UDP: TCP와 같은 전달 확인 및 순서 보장을 제공하지 않음
