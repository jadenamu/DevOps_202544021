파일 내용 검색
  find: 조건에 맞는 파일이나 디렉터리 검색(find . -type f -name "*.sh" #셸 스크립트 파일 찾기)
  grep: 특정 문자열이나 패턴이 있는 줄 검색(grep "ERROR" server.log #ERROR가 포함된 줄 검색)

파이프(|): 앞 명려어의 출력을 뒤 명령어의 입력으로 연결(grep "ERROR" server.log | wc -l # 앞 grep의 애러를 뒤 wc -l에게 넘겨 줄 수를 계산)
리다이렉션(>): 앞 명령어의 출력을 뒤 파일에 저장(grep "ERROR" server.log > errors.txt #errors.txt파일에 에러 메세지 저장)

셸 스크립트 자동화
  $변수명: 변수에 저장된 값 사용
  if [조건]; then 실행코드: 조건문 사용
  for i in *.sh; do: 반복문 사용(현재 디렉터리의 셸 스크립트파일을 연다.)

프로그램: 디스크에 저장된 실행 코드
프로세스: 실행 중인 프로그램
PID: 실행 중인 프로세스의 식별번호

gitignore: git이 추적하지 않는 파일을 새롭게 추적 대상에 포함하지 않도록 한다.

브랜치: 기존 작업 흐름과 분리하여 새로운 기능이나 수정을 진행 할 수 있다.(git switch -c 이름 #브렌치 생성,이동)
Pull Request(PR): 브랜치에서 작업한 변경 사항을 다른 브랜치에 합칠 수 있다. (gh pr create #pr 생성)

네트워크
  IP주소: 네트워크에서 장치를 식별하는 주소
  포트: 해당 장치에서 실행 중인 서비스를 구분하는 번호
  DNS: 도메인 이름에 대응하는 IP 주소를 찾는 시스템
  NAT: 사설 IP 주소를 사용하는 장치가 공유기 등을 통해 인터넷과 통신하도록 주소를 반환하는 방식

  TCP:전송 계층에서 사용하는 프로토콜. 데이터 전달의 신뢰성과 순서를 중요하게 다룸.
  UDP: 같은 프로토콜이지만 전달 확인 및 순서 보장을 제공하지 않음.
